# AX Builder by sysmetrix

공공의 일을 더 잘 작동하게 만드는 시스템과 도구를 소개하는 포트폴리오 사이트입니다.

- **Production**: https://axyouthworker.vercel.app
- **정체성**: `Youth Work × Policy × Strategy × Data × AX`
  청소년 현장과 사업을 출발점으로, 정책·성과·데이터·AX를 연결해 실제 업무에 쓰이는 시스템과 도구를 만듭니다.

## 기술

Next.js(App Router) · React · TypeScript. 정적 우선 구성이며, 글꼴은 Geist와 Pretendard를 사용합니다.

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run verify     # 타입 검사 + 프로덕션 빌드
npm run build && npm start
```

Node.js 22 이상을 권장합니다.
